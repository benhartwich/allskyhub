With this interface any all-sky camera can measure along in SharedSky, whatever software it runs: commercial programs, your own scripts or tinkering projects. The camera sends to the hub over HTTPS. No MQTT, no FTP, no port forwarding. The contract behind it is SPEC §10.

For indi-allsky its configuration is enough, see below. Allsky and every camera that shows its latest image at a fixed address connect without any code of their own through that address ("Allsky / image address" under Connect a camera).

Signing in

Create a free account and choose Connect a camera. The hub then shows you once the station ID (26 characters) and the secret (64 hex characters). You can make a new secret at any time; the old one stops working at once. Every request carries the header

Authorization: Bearer <station ID>:<secret>

The address is {{ base }}/api/connect/v1. All times are ISO 8601 in UTC, for example 2026-11-05T21:40:12Z.

Anmelden

Lege ein kostenloses Konto an und wähle Kamera verbinden. Danach zeigt dir der Hub einmal die Station-ID (26 Zeichen) und das Geheimnis (64 Hex-Zeichen). Ein neues Geheimnis kannst du jederzeit erzeugen, das alte gilt dann sofort nicht mehr. Jede Anfrage trägt den Header

Authorization: Bearer <Station-ID>:<Geheimnis>

Die Adresse ist {{ base }}/api/connect/v1. Alle Zeiten sind ISO 8601 in UTC, zum Beispiel 2026-11-05T21:40:12Z.

2. Send an image: POST /frames

About once a minute, multipart with two parts:

  • metadata: JSON {"time", "exposure_s", "gain", "night", "clock_synced", "stars", "sky_brightness"}; time is the middle of the exposure.
  • image: JPEG, normally a thumbnail (at most 640 px on the long side, 300 kB). Only when the last answer said "want_full_frame": true, the full image (at most 8 MB).

Answer: {"want_full_frame": false}

3. Report a meteor: POST /events

Multipart: metadata as JSON and image, the full image with the meteor, exactly width × height.

    Test mode

    Under /api/connect/v1/test/station, /test/frames and /test/events the hub checks every request the same way but stores nothing, and answers what it understood: {"ok": true, "understood": {…}}. Try out a connection without any risk.

    Limits and errors

    120 requests a minute per station. The hub looks at every image and keeps a thumbnail every 5 minutes; at most 3000 meteors a night, at most 500 MB per station (above that the oldest full images go first). Errors come as {"error": "<code>"}:

    track sind 2 bis 32 Punkte entlang der Spur, in Pixeln des vollen Bildes. peak (0 bis 1) ist optional; ohne ihn misst der Hub die Helligkeit selbst. Antwort: {"id": "meteor-20261105T214000Z"}

    Testmodus

    Unter /api/connect/v1/test/station, /test/frames und /test/events prüft der Hub jede Anfrage genauso, speichert aber nichts, und antwortet, was er verstanden hat: {"ok": true, "understood": {…}}. Damit lässt sich eine Anbindung gefahrlos ausprobieren.

    indi-allsky

    {% if en %}

    indi-allsky needs no installation. In its configuration under SyncAPI: turn it on, Base URL {{ base }}/indi-allsky, Username the station ID, API Key the secret, sync images: every image. indi-allsky then sends its location, lens, exposure, star count and the number of detected meteor trails with every image.

    What happens to the data

    • Images stay yours. The hub shows them only where you allow it, and always with the station's name.
    • Measurements (times, tracks, paths, rates, sky brightness) are shared under CC BY 4.0 with the station's name; only so can they go on to scientific partners.
    • Location: the exact place is used only for the calculations; publicly it is always rounded.
    {% else %}

    indi-allsky braucht keine Installation. In der Konfiguration unter SyncAPI: einschalten, Base URL {{ base }}/indi-allsky, Username die Station-ID, API Key das Geheimnis, Bilder synchronisieren: jedes Bild. indi-allsky schickt dann mit jedem Bild Standort, Objektiv, Belichtung, Sternzahl und die Zahl erkannter Meteorspuren.

    Was mit den Daten passiert

    • Bilder bleiben deine. Der Hub zeigt sie nur dort, wo du es erlaubst, und immer mit dem Namen der Station.
    • Messwerte (Zeiten, Spuren, Bahnen, Raten, Himmelshelligkeit) teilt der Hub unter CC BY 4.0 mit dem Namen der Station; nur so kann er sie an wissenschaftliche Partner weitergeben.
    • Standort: Der genaue Ort dient nur der Rechnung, öffentlich steht er immer gerundet.
