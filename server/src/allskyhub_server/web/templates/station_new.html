2. Deine Station

{% if software == 'image-url' %}

Die Adresse, unter der deine Website oder deine Kamera immer das neueste Bild zeigt (JPEG oder PNG, Port 80 oder 443). Der Hub fragt alle 30 Sekunden bis 5 Minuten nach, je nachdem wie oft sich das Bild ändert, und holt es nur, wenn es neu ist. Den Traffic trägt dein Server.

Klick auf die Karte setzt den Ort. Er wird genau gebraucht, um Bahnen zu rechnen; öffentlich erscheint er nur gerundet.

Nachweis, dass es deine Kamera ist

Ein Admin prüft jede Station von Hand. Hilfreich ist ein Screenshot der Einstellungsseite deiner Kamera, auf dem die Adresse steht, ein Foto der Kamera an ihrem Ort oder ein Link auf deine eigene Website mit dem Bild.
