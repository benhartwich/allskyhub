{{ 'allskyhub next to Allsky' if en else 'allskyhub neben Allsky' }}

{{ 'Deutsch' if en else 'English' }}
{% if en %}

Your Raspberry Pi already runs Allsky ↗? allskyhub installs next to it, without a new SD card. Allsky stays as it is; you switch between the two with one command, because only one program can use the camera at a time.

{% else %}

Auf deinem Raspberry Pi läuft schon Allsky ↗? allskyhub lässt sich daneben installieren, ohne neue Speicherkarte. Allsky bleibt, wie es ist; du wechselst mit einem Befehl zwischen beiden, weil immer nur ein Programm die Kamera benutzen kann.

{% endif %}

{{ 'What you need' if en else 'Was du brauchst' }}

    {% if en %}
  • A Raspberry Pi 4 or 5 with Allsky and a ZWO camera (tested with the ASI678MC) or a Raspberry Pi HQ camera (supported, not yet tested on real hardware)
  • SSH access to the Pi and about 20 minutes
  • An allskyhub account: ask for access
    • {% else %}
  • Einen Raspberry Pi 4 oder 5 mit Allsky und einer ZWO-Kamera (getestet mit der ASI678MC) oder der Raspberry-Pi-HQ-Kamera (unterstützt, noch nicht an echter Hardware getestet)
  • SSH-Zugang zum Pi und etwa 20 Minuten
  • Ein allskyhub-Konto: Zugang beantragen
    • {% endif %}

1. {{ 'Get allskyhub' if en else 'allskyhub holen' }}

{{ 'git and the Python tool uv, then the source code:' if en else 'git und das Python-Werkzeug uv, dann den Quellcode:' }}

sudo apt install -y git
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.local/bin/env
git clone https://github.com/benhartwich/allskyhub ~/allskyhub

2. {{ 'User and folders' if en else 'Benutzer und Ordner' }}

{{ 'allskyhub runs as its own user and keeps its pictures in /var/lib/allskyhub-agent.' if en else 'allskyhub läuft als eigener Benutzer und legt seine Bilder unter /var/lib/allskyhub-agent ab.' }}

sudo useradd --system --home-dir /var/lib/allskyhub-agent --no-create-home \
  --shell /usr/sbin/nologin --groups video allskyhub
sudo install -d -o allskyhub -g allskyhub -m 0750 /var/lib/allskyhub-agent /var/lib/allskyhub-agent/data
sudo install -d /opt/allskyhub-agent/lib /etc/allskyhub-agent

{{ 'With a ZWO camera, also take Allsky’s copy of the ZWO driver:' if en else 'Mit einer ZWO-Kamera zusätzlich Allskys Kopie des ZWO-Treibers übernehmen:' }}

sudo install -m 0755 ~/allsky/server/assets/asi_sdk/lib/armv8/libASICamera2.so.1.39 /opt/allskyhub-agent/lib/
sudo ln -sfn libASICamera2.so.1.39 /opt/allskyhub-agent/lib/libASICamera2.so

{{ 'If the version number differs on your Pi, use the file that is there (ls ~/allsky/server/assets/asi_sdk/lib/armv8/).' if en else 'Steht auf deinem Pi eine andere Versionsnummer, nimm die Datei, die dort liegt (ls ~/allsky/server/assets/asi_sdk/lib/armv8/).' }}

3. {{ 'Install' if en else 'Installieren' }}

{{ 'Builds allskyhub into its own folder; this takes a few minutes on a Pi 4 (the build cache stays in /root/.cache/uv).' if en else 'Baut allskyhub in einen eigenen Ordner; das dauert auf einem Pi 4 ein paar Minuten (der Zwischenspeicher bleibt unter /root/.cache/uv).' }}

V=$(git -C ~/allskyhub rev-parse --short=7 HEAD)
R=/opt/allskyhub-agent/releases/$V
sudo install -d $R
cd ~/allskyhub && sudo env UV_PYTHON_DOWNLOADS=never UV_PROJECT_ENVIRONMENT=$R/.venv \
  sh -c "$(command -v uv) venv -q --python /usr/bin/python3 $R/.venv && $(command -v uv) sync -q --frozen --no-dev --no-editable --package allskyhub-agent"
sudo ln -sfn releases/$V /opt/allskyhub-agent/current

4. {{ 'Settings' if en else 'Einstellungen' }}

{{ 'Your location (decimal degrees; replace the example values), time zone and camera. You can change all of it later on the hub. The file stays readable for allskyhub only.' if en else 'Dein Standort (Dezimalgrad; die Beispielwerte ersetzen), Zeitzone und Kamera. Ändern kannst du alles später auf dem Hub. Die Datei bleibt nur für allskyhub lesbar.' }}

echo '{"latitude": 50.00, "longitude": 10.00, "timezone": "Europe/Berlin", "camera": "zwo-asi678mc"}' \
  | sudo -u allskyhub sh -c 'umask 077; cat > /var/lib/allskyhub-agent/settings.json'

{{ 'With the Raspberry Pi HQ camera write "camera": "rpi-hq".' if en else 'Mit der Raspberry-Pi-HQ-Kamera "camera": "rpi-hq" eintragen.' }}

echo 'ALLSKYHUB_AGENT_ARGS="--asi-sdk /opt/allskyhub-agent/lib/libASICamera2.so run --data /var/lib/allskyhub-agent/data --settings /var/lib/allskyhub-agent/settings.json --hub https://allskyhub.org --http 0.0.0.0:8080"' \
  | sudo tee /etc/allskyhub-agent/allskyhub-agent.env

{{ 'With the HQ camera leave out "--asi-sdk /opt/allskyhub-agent/lib/libASICamera2.so".' if en else 'Mit der HQ-Kamera "--asi-sdk /opt/allskyhub-agent/lib/libASICamera2.so" weglassen.' }}

5. {{ 'Service, switching with Allsky' if en else 'Dienst, im Wechsel mit Allsky' }}

{{ 'Starting allskyhub stops Allsky and the other way round. After a reboot the Pi starts with Allsky as before.' if en else 'Startet allskyhub, stoppt Allsky, und umgekehrt. Nach einem Neustart startet der Pi wie bisher mit Allsky.' }}

sudo cp ~/allskyhub/image/files/etc/systemd/system/allskyhub-agent.service /etc/systemd/system/
sudo install -d /etc/systemd/system/allskyhub-agent.service.d
printf '[Unit]\nConflicts=allsky.service\nAfter=allsky.service\n' \
  | sudo tee /etc/systemd/system/allskyhub-agent.service.d/allsky-switch.conf
sudo systemctl daemon-reload

6. {{ 'Start and pair' if en else 'Starten und koppeln' }}

sudo systemctl start allskyhub-agent
{% if en %}

Open http://<address-of-your-pi>:8080 in a browser on your network. The page shows a pairing code like ABC-DEF; enter it under Pair a camera. The live picture shows up on the hub a minute later.

{% else %}

Im Browser in deinem Netz http://<Adresse-deines-Pi>:8080 öffnen. Die Seite zeigt einen Kopplungscode wie ABC-DEF; den unter Kamera koppeln eingeben. Eine Minute später ist das Livebild auf dem Hub.

{% endif %}

7. {{ 'Optional: bring your old pictures' if en else 'Optional: alte Bilder mitnehmen' }}

{{ 'allskyhub takes over Allsky’s nights: images, keograms, star trails, timelapses and meteors. On the same disk it links the files instead of copying them, so it needs hardly any space. First a dry run, then without --dry-run:' if en else 'allskyhub übernimmt Allskys Nächte: Bilder, Keogramme, Sternspuren, Zeitraffer und Meteore. Auf derselben Platte verlinkt es die Dateien statt sie zu kopieren und braucht kaum Platz. Erst ein Probelauf, dann ohne --dry-run:' }}

sudo /opt/allskyhub-agent/current/.venv/bin/allskyhub-agent import-allsky \
  --from ~/allsky --data /var/lib/allskyhub-agent/data \
  --settings /var/lib/allskyhub-agent/settings.json --dry-run

{{ 'Allsky in another folder: adjust --from. Coming from indi-allsky: import-indi-allsky instead, see the' if en else 'Liegt Allsky woanders, --from anpassen. Von indi-allsky: import-indi-allsky, siehe die' }} {{ 'guide' if en else 'Anleitung' }} ↗.

{{ 'Switching and updating' if en else 'Wechseln und aktualisieren' }}

sudo systemctl start allsky            # {{ 'back to Allsky' if en else 'zurück zu Allsky' }}
sudo systemctl start allskyhub-agent   # {{ 'back to allskyhub' if en else 'wieder allskyhub' }}
{% if en %}

Stay with allskyhub after reboots: sudo systemctl disable allsky && sudo systemctl enable allskyhub-agent. To update, run git -C ~/allskyhub pull and step 3 again, then sudo systemctl restart allskyhub-agent. Note: Allsky starts itself again when the camera is plugged back in.

{% else %}

Auch nach Neustarts bei allskyhub bleiben: sudo systemctl disable allsky && sudo systemctl enable allskyhub-agent. Zum Aktualisieren git -C ~/allskyhub pull und Schritt 3 wiederholen, dann sudo systemctl restart allskyhub-agent. Hinweis: Allsky startet sich selbst wieder, wenn die Kamera neu eingesteckt wird.

{% endif %}
